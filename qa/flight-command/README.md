# Flight command workbench

Serve the repository root and open `/qa/flight-command/`:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Plan each aerie's future launches with Hold or an adjacent-road order. Existing
flights keep their committed destination. Compare exposed mines, a pressured
ground screen and prepared anti-air with five paid defender responses.

See [design and review](../../docs/FLIGHT_COMMANDS.md),
[tactical evidence](evaluation-summary.md), and
[touch/desktop checks](browser-evidence/results.json).

This is an isolated QA prototype. Production runtime and campaign progression
are unchanged. No merge or deployment is authorized by this workbench.
