## Confirmed problem and bounded policy

Read the independent dense review's exact-renderer transcripts and report. Legal ordinarily snapped adjacent sites at ordinary desktop scale can have full labels paint over earlier timestamps and names; this was not merely an impossible pile or phone-only model. Horizontal edge clamping and short fields compounded the issue. Existing single-memory containment tests did not cover it.

The remedy keeps every on-screen compact stale glyph at its actual remembered world position. It does not introduce displaced labels, leader lines, new enemy selection, or command/inspection branches. It admits a full badge only at its own anchored position when within two-dimensional bounds and clear of all reserved on-screen stale glyph rectangles and already admitted badges. All glyphs are reserved before any badge, preventing later-road glyphs from covering an earlier badge. Short/crowded fields can honestly show zero full badges.

Fallback is explicit: dashed markers remain stale, a map hint directs the player to Pause, and a conditional semantic Pause disclosure contains all frozen details, including off-camera records. This is not a guarantee that every full badge always fits or that every possible existing renderer decoration is collision-free. Native readability remains to be checked.

## Information boundary and determinism

- Layout input is the detached observation's frozen memory records plus immutable building names, viewport geometry and measured text. Sorting uses frozen lane/x/y/id. It never examines hidden current actors, current HP, production, destruction, private economy or current enemy choice.
- The observation is not mutated. Hidden upgrades/damage/sales do not change badge decisions, glyph locations, text, minimap or frozen details. Reordered incoming records are deterministically sorted for layout/details.
- The Pause list states name, level, frozen observation time, unknown current health/production, road and remembered x-position. It does not infer whether a structure still exists or fabricate health/recency. All information was already in the side's authorized observation.
- Terminal reveal, empty memories and ordinary-mode reset clear the list, disclosure and hint. No new engine action, serialized field, profile preference, import/export path, audio policy or RNG use was introduced.
