# Independent fog prototype review: initial risk map

Scope: local bounded QA prototype only. Reviewed source v0.20.2 and the optional-fog design. No source implementation, browser, deployment or external write was performed. No AGENTS.md was found in the source tree or its visible shared parents. Repository checks are `npm test` and `node scripts/check.mjs`; independent checks below will be narrower rather than duplicating the full suite.

## Highest-risk boundaries

1. **Observation must be a real data boundary.** Pass detached whitelisted state and immutable definitions/map, not a raw Game, spread of a Game, serialize(), or methods whose return values expose raw entities. Strip hidden economy, stats, base health and citadel option internals. A last-seen structure must omit HP, progress, cooldown, invested gold and targeting identity. Numeric IDs in the model are acceptable local implementation details, but should not appear as UI/intelligence clues. Enemy target-lock IDs are not observable intent.
2. **VFX/event lifetime, not only array filtering.** `BattleVFX.update` keeps a WeakSet of event object identities and its own particles/shake. New detached copies each frame can replay an event indefinitely. Retaining only currently visible arrays does not remove already ingested particles after sight loss. Raw projectiles expose source and target endpoints even when their present point is visible. Suppress hidden events before ingestion and use stable allowed event identity or a bounded presentation event queue. A conservative no-projectile/no-particle experimental policy is safer than a partial leak.
3. **Null is not dead or free.** Renderer base health divides hp/maxHp and `citadelOptionStatus` reads both bases, resources and per-side counters. A hidden base needs an explicit known-location/unknown-status rendering path, not fake zero or full health. The enemy regeneration label, purchase wait, affordability reason and healed/shot totals must not be derived from a hidden raw record.
4. **One information snapshot per decision phase.** Stock structures spawn before units, units move before base fire, then AI runs. Capturing visibility at different positions in those loops risks a first-mover advantage. Cache symmetric visibility once for combat decisions, publish a fresh post-resolution view, and use equal rules for player/AI direct commands. A side's `_ai` multi-action sequence must not accidentally expose the opponent's intervening hidden updates.
5. **AI has multiple independent reads.** Audit producers, watchtower counters, gryphon avoidance, lane pressure, Volley clustering and `chooseAICitadelOption`. Replacing only the initial enemies array is insufficient. Use visible units and frozen remembered structures. Unknown producers cannot be replaced by live count zero or hidden production progress.
6. **Fog mechanics do not expand attack rules.** Vision may cross roads, but automatic air stays 300 acquire / 420 retain with current eligibility and ID tie-breaking. A hidden structure may not steer a troop. Known enemy citadel location may guide forward movement, without supplying hidden HP/status. Splash may hit hidden units, but only own aggregate rewards are intentional disclosure.
7. **Restore is an information boundary.** Serialize both sides' memories with finite timestamps, bounded records, strict keys, valid enemy side/type/coordinates, unique identity and a stable deterministic cap/eviction rule. Do not clear a stale building merely because the hidden live entity disappeared or changed. Re-observed empty position clears it. Game.restore should be deterministic without changing RNG or memory at the read/serialize boundary.
8. **Isolation has to be demonstrable.** QA-only shell should not import normal app setup, write profile/localStorage keys, alter live default selection, or link the fog rule into campaigns/trials. Identity must reject non-Classic/timed/bridge combinations. Existing rules should remain structurally identical and retain exact RNG/action/state behavior.

## Targeted independent checks to run on completed artifacts

- For each side, identical observed scene + memory + RNG with unseen building type/level/progress/HP, units, enemy resources and citadel records varied: deep-equal observation and equal AI decisions, purchases, Volley targets, front and audio inputs. Exempt terminal outcome and the documented own reward channel. Use decision-level tests: changing future hidden spawns legitimately consumes the legacy shared simulation RNG, so a whole-world continuation is not a clean read-leak test without holding the RNG at the decision boundary.
- Mutate one returned observation and confirm the simulation and later observations are unchanged. Enumerate façade keys/methods. Exercise repeated observe calls while paused and verify no simulation/RNG mutation.
- Observe an enemy building, lose sight, upgrade/sell/destroy it, then re-observe the position. Check frozen silhouette and no HP/production/status fields; test new building at same position, same-tick observations and deterministic memory cap.
- Attack/cast at precise inclusive visibility and range boundaries, both sides. Reject hidden Volley before spending. Edge splash may change own gold/kills but cannot emit hidden death/hit/projectile/audio coordinates.
- Visible event then sight loss; hidden event then later sight gain; repeated frames/paused frames; pan into an unseen region. Compare event/audio counts and confirm no replay, trailing particles, minimap actor or shake.
- Corrupt memory side/type/id/level/lane/time/coordinates/keys/length, duplicate entries and missing sides; require rejection without mutating the submitted save or a running game. Verify restore observation and short deterministic continuation for both sides.
- Select a small predecessor cohort covering default rules, legacy and current citadel plus bridge modes, paired paid actions, update timing, RNG and cross-restores. Source-compare all unchanged published rule definitions and live app/profile files.
- Native browser acceptance remains required at 320x430, 390x650, 844x390 and desktop. Inspect unknown base marker, dashed memory, visible-contact contrast, HUD/legend occlusion, minimap navigation, hidden-aim feedback, repeated/cancelled touches, pointercancel/blur/document-hidden pause, and low-quality/reduced-motion variants. Static checks are not equivalent to browser evidence.
