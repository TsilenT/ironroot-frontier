## Dense remembered buildings

The independent synthetic review demonstrated that normal 140-world-unit snapped spacing produces overlapping full badges at a 1139 × 398 desktop field. Later opaque badges covered earlier names and frozen timestamps. The remedy does not try to show every full label at once:

- Muted dashed glyphs and minimap marks stay at their true frozen positions. Compact field text gives a two-letter type abbreviation and last-observed level. No health/production bar is invented.
- Sort only detached memory records by lane, x, y and internal ID for deterministic processing; IDs are never displayed. Reserve every visible stale glyph before admitting labels.
- A full badge stays centered beneath its own marker. Admit it only if it is entirely within the conservative HUD/tool/map-control-safe field area and intersects no reserved glyph or previously admitted badge. There is no edge clamping, label displacement or general packing. A cramped/short field intentionally omits badges rather than clipping or overlapping them.
- The existing field hint conditionally says `Dashed markers: last seen · Details in Pause`. A Pause disclosure contains every frozen full name, level, observation time, road and known-map position, explicitly stating that current health and production are unknown. The list is scrollable and each entry keyboard-focusable. The Pause control also references this guidance accessibly because existing compact CSS hides the visual map hint.
- The list is rebuilt only when its frozen text changes. Otherwise the same nodes/focus stay mounted. Focus is captured before hiding, including the summary; empty/re-observed/terminal/ordinary transitions clear the list/cue and move focus to a valid control when necessary.
- This changes presentation only. It adds no enemy action/selection path, new paid command, visibility rule or stored preference.
